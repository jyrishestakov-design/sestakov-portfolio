# UFO-minimäng ja mänguriba — tööplaan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Uus UFO-minimäng ja sektsioonitüüp „Minimängud“, kus Viking Rideri ja UFO demod jooksevad kõrvuti ja valitud mäng laieneb täislaiusse.

**Architecture:** Mängureeglid on puhtad funktsioonid (`js/ufo-logic.js`, Node'is testitav). Joonistamine ja sisend on failis `js/ufo.js`, mis on ehitatud `js/viking.js` mustri järgi: canvas, ResizeObserver, IntersectionObserver ja demo-, play- ja over-režiim. Mänguriba (`js/games.js`) haldab valikuvaadet ja blokeerib sisendi püüdva `keydown`-kuulajaga. `js/render.js` saab tüübi `games`.

**Tech Stack:** puhas JS (ES2017, ilma moodulite laadijata), canvas 2D, Node 22 `node:test`, Playwright, Python 3 (PyYAML).

**Spec:** `docs/superpowers/specs/2026-10-27-ufo-mang-design.md`

## Global Constraints

- `js/viking.js` jääb muutmata.
- Väliseid teeke ega build-sammu ei lisata. Sprite'id on pikslikunst koodis (data-URI või canvas'ele joonistatud).
- Mänguriba kõrgus on 240 px, ≤720 px ekraanil 180 px. Taust on alati tume (`#0C0D11`).
- Neoonsildid inglise keeles: `COWS IN MOTHER SHIP: n`, `MEN IN BLACK IN MOTHER SHIP: n`. Ülejäänud mängutekstid tulevad lehe keele järgi.
- Väärtused: `BEAM_MS = 350`, `BEAM_COOLDOWN_MS = 600`, kiire pikkus = 0.5 × mänguala kõrgus, `START_LIVES = 3`, `MAX_LIVES = 5`, `LIFE_EVERY = 5`, `WIN_AT = 100`, `INVULN_MS = 1500`.
- Lehe ülejäänud osa jääb pikslitäpselt samaks (`compare --skip-header`, `#ride` peidetud).
- Testikäsud: `node --test tests/*.test.js`, `node tests/e2e.mjs check`, `node tests/e2e.mjs compare <baseline> --skip-header`, `python3 tests/check_config.py`.

## Review Focus

1. Keelevahetus UFO mängu ajal: mäng ei tohi uuesti alata ega kuulajaid dubleerida; nupu „← Mängud“ tekst vahetub (test Task 3).
2. Valikuvaatest laiendamisel peab UFO canvas suurenema riba laiuseni (test Task 3).
3. X all hoidmine: kiir ei korda jahtumisajata (test Task 1, `beamReady`).
4. Kokkupõrge haavamatuse ajal: elu ei kao uuesti (test Task 1, `hit`).
5. 100. objekt annab ka lisaelu: elud ≤ 5 ja `won` on `true`; uus mäng algab puhta olekuga (test Task 1).

### Task 1: mängureeglid `js/ufo-logic.js`

**Files:** Create `js/ufo-logic.js`, `tests/ufo.test.js`

**Interfaces — Produces (`window.UfoLogic`):**
- konstandid `BEAM_MS, BEAM_COOLDOWN_MS, START_LIVES, MAX_LIVES, LIFE_EVERY, WIN_AT, INVULN_MS` (väärtused Global Constraints'ist)
- `newGameState() -> { lives: 3, cows: 0, men: 0, total: 0, won: false, over: false, invulnUntil: 0 }`
- `beamReady(now: number, lastBeamAt: number) -> boolean`, mis on tõene, kui `now - lastBeamAt >= BEAM_MS + BEAM_COOLDOWN_MS`
- `beamHits(ufo: {x, w, bottom}, obj: {x, w, top}, beamLen: number) -> boolean`. Tabab, kui horisontaalsed lõigud `[x, x+w]` lõikuvad ja `0 <= obj.top - ufo.bottom <= beamLen` (y kasvab alla).
- `collides(a: {x, y, w, h}, b: {x, y, w, h}) -> boolean`, range piirdekastide lõikumine (servade puudutus ei loe)
- `teleport(state, kind: 'cow'|'man') -> state`. Tagastab uue objekti: `cows` või `men` +1, `total` +1. Kui `total % LIFE_EVERY === 0`, siis `lives = min(MAX_LIVES, lives + 1)`. `won = total >= WIN_AT`.
- `hit(state, now) -> state`. Kui `now < invulnUntil`, siis muutmata. Muidu `lives - 1`, `invulnUntil = now + INVULN_MS` ja `over = lives <= 0`.

- [ ] **Step 1: testid `tests/ufo.test.js`**:
  - `beamHits({x:100,w:40,bottom:50},{x:110,w:20,top:120},100)` → true; `{x:150,…}` → false (kõrval); `top:200` → false (liiga kaugel); `top:40` → false (ufost kõrgemal)
  - `collides({x:0,y:0,w:10,h:10},{x:5,y:5,w:10,h:10})` → true; `{x:10,y:0,…}` → false
  - 4× `teleport(…,'cow')` + 1× `'man'` → `{cows:4, men:1, total:5, lives:4}`
  - 10 korda `teleport` alates `lives:5` → `lives` jääb 5 (Review Focus 5)
  - 99× teleport → `won:false`; 100. → `won:true`, `lives <= 5`; `newGameState()` pärast → `total:0, won:false` (Review Focus 5)
  - `hit(newGameState(), 1000)` → `lives:2, invulnUntil:2500`; sama olek `hit(…, 2000)` → `lives:2` (Review Focus 4); `hit(…, 2500)` → `lives:1`; kolm lööki → `over:true`
  - `beamReady(949, 0)` → false, `beamReady(950, 0)` → true (350 + 600 = 950; Review Focus 3)
- [ ] **Step 2:** `node --test tests/ufo.test.js` → FAIL (moodulit pole)
- [ ] **Step 3:** kirjuta `js/ufo-logic.js` (sama UMD-muster nagu `js/core.js`)

### Task 2: UFO mäng `js/ufo.js` ja tüüp `games` (üks mäng)

**Files:** Create `js/ufo.js`, `tests/fixtures/ufo-only.json`; Modify `js/render.js`, `js/i18n-strings.js`, `index.html`

**Interfaces:**
- Consumes: `UfoLogic.*` (Task 1)
- Produces:
  - `window.startUfo(mount: HTMLElement, texts: object) -> { setTexts(texts) }`. Canvas täidab mounti, suurus ResizeObserveriga nagu `viking.js` (madal sisemine resolutsioon, `imageSmoothingEnabled = false`). Režiimid `demo | play | over | win`. Sisend: ↑ ↓ lend, ← → kiirus, X kiir, tühik alustab või kordab. Klaviatuurikuulaja on `window` peal ja kontrollib nähtavust `onScreen()` abil nagu `viking.js`. Puudutus: `fx > 0.75` kiir, `fy < 0.5` üles, muidu alla. Demos lendab ufo ise ja laseb kiirt, kui objekt on all.
  - Joonistus: tähistaevas ja kuu; maapind; ufo (hall taldrik, klaaskuppel, roheline pea kahe musta silmaga, vilkuvad tuled); lehmad 3 suuruses (laius ~14/20/28 loogikapikslit), MIB-mees (must ülikond, valge särk, prillid); kiir on poolläbipaistev roheline koonus; tabatud objekt hõõgub roheliselt, tõuseb ja kaob 400 ms jooksul. Ülal kaks neoonsilti (roosa/tsüaan, `shadowBlur`), elud südametena paremal. Võidul laskub emalaev (lai taldrik ülaservast), roheline kiir tõmbab ufo üles, kõik lahkub üles ja tuleb tekst `texts.ufoWin`.
  - Testkonks ainult siis, kui `window.__UFO_TEST__ === true`: `window.__ufoDebug = { mode(), state(), spawnBelow(kind) }`. `spawnBelow` paneb ufo alla, kiire ulatusse, `kind` tüüpi objekti.
  - `RENDERERS.games(section)`: `<section class="game-strip games-strip" id={section.id||'ride'}>`. Sees on iga sees oleva mängu jaoks `<div class="gm-half" data-game="viking|ufo">` ja selles mount: viking → `<div id="viking-runner">`, ufo → `<div class="ufo-runner">`. Kui ainult üks on sees: `data-view` = selle mängu nimi, valikuvaadet pole. Sõlm luuakse üks kord, keelevahetusel kutsutakse `setTexts`. Mõlema korral on see Task 3 osa; siin piisab ühe mängu juhust.

  - `index.html`: `.ufo-runner { width:100%; height:240px; touch-action:none; cursor:pointer }` (≤720 px: 180 px), `.gm-half { position:relative }`, `<script src="js/ufo-logic.js" defer>` ja `<script src="js/ufo.js" defer>` enne faili `render.js`.
